# 🦋 INSECT-3D-MODELS

Interactive 3D Insect Models in browser!

**Live Demo:** https://insect-3-d.vercel.app/

### Features
- Realistic 3D insects - Butterfly, Beetle, Dragonfly & more
- Zoom, Rotate, Interactive controls
- Built with Three.js + WebGL
- Works on Mobile & Desktop

### Tech Stack
- Three.js
- HTML, CSS, JavaScript
- GLTF / GLB 3D models
- Vercel hosting

### How to use
Just open https://insect-3-d.vercel.app/ and explore!

### Folder Structure
- `assests/` - 3D models (.glb files)
- `tools/` - helper scripts
- `index.html` - main website
